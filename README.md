# A.NAV — פאנל מחשבונים פיננסיים

גרסת הפיתוח נמצאת בענף `dev`. ענף `main` נשאר גרסת הייצור עד לאישור מפורש.

## פיתוח
הפעלת האתר: שרת סטטי (למשל `python3 -m http.server 8000`) ופתיחת `index.html`.
לא צריך npm install או תלויות חיצוניות כדי לבנות את קוד האפליקציה.

- `index.html`: מבנה HTML וקישורים לקובצי עיצוב וקוד בלבד.
- `styles/src/*.css`: מקור העיצוב לפי נושאים ובסדר מוגדר.
- `scripts/src/*.js`: קוד המקור לפי מודולים לוגיים בסדר הטעינה המקורי.
- `styles/app.css`, `scripts/app.js`: קובצי Build להפצה, לא עורכים אותם ידנית.
- `tools/manifest.json`: סדר החיבור; חובה לשמר אותו ללא תכנון מחדש.
- `backups/2026-11-01-main/Index.html`: גיבוי מדויק של המקור שהיה ב-main בעת יצירת dev.
- `tests/`: בדיקות מודל ויושרה; `.github/workflows/`: בדיקות אוטומטיות לענף dev.

## פקודות
```bash
npm run build
npm run check
npm test
```

**הערת תאימות:** הפיצול הראשון הוא מבני בלבד: שני קובצי ה-build זהים בתוכנם לקוד CSS ו-JavaScript המשובץ ב-`Index.html` הישן, וה-DOM זהה. אין להזיז פונקציות בין קטעי מקור בלי לבדוק תלויות וסדר הרצה.

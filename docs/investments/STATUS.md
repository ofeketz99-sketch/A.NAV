## 3. איך לבדוק את האתר

**בחלונית הדפדפן של האפליקציה:** האתר רץ שם מקומית בכתובת `http://localhost:8765`. בדפדפן הזה כבר נמצאים הנתונים שייבאת בבדיקה.

**בדפדפן הרגיל שלך:**
1. בתיקיית הפרויקט מריצים `node .claude/serve.cjs 8765`.
2. פותחים `http://localhost:8765`. הדפדפן הרגיל מתחיל בלי נתונים, וזו הזדמנות לבדוק ייבוא מאפס.

**מה כדאי לנסות:**
- [ ] מעבר בין מחשבונים להשקעות, וחזרה. המחשבונים צריכים להיראות ולעבוד כמו קודם.
- [ ] נתונים ← ייבוא מאקסל ← לבחור את הקובץ. לעבור על הגיליונות בתצוגה המקדימה, ואז "ייבוא".
- [ ] ייבוא חוזר של אותו קובץ. אמור להופיע "אין שורות חדשות לייבוא".
- [ ] לוג: לפתוח עסקה, לערוך פעולה, למחוק ולבטל את המחיקה.
- [ ] פעולה חדשה: לבדוק שהעמלה ממולאת לבד, ושמכירה מעבר לכמות המוחזקת נחסמת.
- [ ] פילוח תיק: "רענון מחירים". שער הדולר מתעדכן מ-ECB, והמניות נשארות ידניות עד שיחובר ספק.
- [ ] ביצועים: הגרף, ובחירת טווח (חודש / 3 חודשים / שנה / הכול).
- [ ] נתונים ← ייצוא לאקסל. לפתוח את הקובץ ב-Excel ולוודא שהתאריכים והמספרים תקינים. זה **עוד לא נבדק ב-Excel עצמו**.
- [ ] הכול גם במסך טלפון.

- **שווי חשבון:** גם רישום מהברוקר וגם חישוב מהאחזקות, עם הצגת הפער.
- **משקל אחזקה:** מתוך כל התיק כולל מזומן.
